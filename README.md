# CosmicObjectsClassification

## О проекте

Проект посвящён предсказанию распределений ответов пользователей на вопросы из опросника UKIDSS о морфологии галактик посредством анализа их изображений.

Модель предсказывает, как распределились ответы людей на каждый вопрос. Такой подход позволяет учитывать, что разные пользователи могут по-разному интерпретировать одну и ту же галактику.

Для решения задачи была разработана свёрточная нейронная сеть (CNN) с использованием **Multi-Task Learning**. Модель одновременно работает с десятью вопросами опросника, а для каждого из них использует отдельную выходную голову. Это позволяет учитывать разное количество вариантов ответа у разных вопросов.

Основная цель проекта — оценить качество предсказанных распределений ответов людей.

## Данные

В проекте используется датасет с изображениями галактик и результатами опроса UKIDSS.

[Источник датасета — Zenodo](https://zenodo.org/records/13357341).

На этапе подготовки данных были выполнены следующие действия:
- Оставлено 35% случайно выбранных записей из исходного CSV-файла.
- Для записей добавлены пути к соответствующим изображениям.
- Удалены столбцы, которые не используются при обучении модели.
- Данные разделены на обучающую, валидационную и тестовую выборки в соотношении 70/15/15.

В качестве целевых значений используются не отдельные ответы, а их распределения. Благодаря этому модель обучается воспроизводить результаты опроса, а не просто выбирать наиболее популярный вариант.

## Архитектура модели

В основе решения лежит свёрточная нейронная сеть, построенная на PyTorch.

Модель состоит из двух основных частей:

- **Общая часть (backbone)** — извлекает признаки из изображений галактик с помощью свёрточных слоёв, ReLU и Max Pooling. Далее используются Adaptive Average Pooling и полносвязные слои.
- **Выходные головы (heads)** — отдельные полносвязные слои для каждого вопроса. Они получают общие признаки от CNN и формируют предсказания с учётом количества вариантов ответа в конкретном вопросе.

Такой подход позволяет не обучать десять независимых моделей, а использовать общие визуальные признаки для решения нескольких связанных задач.

В архитектуре также применяется Dropout для снижения риска переобучения.

## Обучение

Для обучения модели используются:
- **PyTorch** — построение и обучение нейронной сети.
- **Adam** — оптимизатор с learning rate 0.001.
- **KL Divergence Loss** — функция потерь для сравнения предсказанных и целевых распределений.

Поскольку не каждый вопрос имеет ответ для каждой галактики, при расчёте функции потерь используется маска. Она позволяет исключать неприменимые вопросы из обучения, чтобы они не влияли на обновление весов модели.

Обучение проводилось в течение 20 эпох. Для дальнейшей оценки выбиралась модель с лучшим результатом на валидационной выборке.

## Результаты

За время обучения значение validation loss уменьшилось примерно с **0.4183 до 0.3116**.

Дополнительно качество предсказаний оценивалось с помощью MAE и сравнения наиболее вероятных вариантов ответа.

Примеры accuracy для отдельных вопросов:

| Вопрос | Accuracy |
|---|---:|
| Smooth or featured? | 90% |
| How rounded? | 84% |
| Disk edge-on? | 87% |
| Spiral arm count | 56% |

Результаты показывают, что качество предсказаний зависит от конкретного вопроса. Например, модели значительно проще определить, является ли галактика гладкой или структурированной, чем правильно предсказать количество спиральных рукавов.

При этом accuracy не отражает качество предсказанного распределения целиком, поэтому она рассматривается вместе с метриками, оценивающими различия между распределениями.

## Что было изучено в ходе проекта

При работе над проектом удалось на практике разобраться с несколькими важными темами машинного обучения:

- Построение CNN для обработки изображений.
- Принципы работы свёрточных и pooling-слоёв.
- Использование Dropout для борьбы с переобучением.
- KL Divergence и сравнение вероятностных распределений.
- Multi-Task Learning и архитектуры с несколькими выходными головами.
- Обучение модели с маскированием неприменимых целевых значений.
- Оценка качества предсказаний с помощью нескольких метрик.
